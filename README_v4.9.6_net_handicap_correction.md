# Hockey Guys Golf League v4.9.6 — Net Handicap Correction

This package keeps match-play scoring on relative strokes, but fixes individual player net stats and low-net leaderboards to use each player's own rounded 9-hole playing handicap.

Example: Drexy / Bobby Drexler with GHIN index 10.0 on the back nine uses a 4-stroke playing handicap for individual net stats, so 39 gross = 35 net.

Upload these root files to GitHub Pages and replace the existing versions:

- index.html
- admin.html
- public.js
- admin.js
- polish.js
- style.css
- theme-polished.css
- robots.txt

No Apps Script redeploy is required.
